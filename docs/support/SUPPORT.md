# Rebilix Support (Free Beta)

Rebilix is currently live in beta at https://o-ps-iq.vercel.app. We're in **free beta**. There is
**no billing and no payment** — you never need a credit card, and there is nothing to pay for. If
something goes wrong, this page tells you exactly what to do.

**Contact:** support@opsiq.solutions (during beta)

When you email us, please include the details listed in
[What to include in a support request](#what-to-include-in-a-support-request) so we can help fast.

---

## What to do if signup fails
1. Make sure your **email is valid**, your **password is at least 8 characters**, and you entered a
   **workspace name**.
2. If you see an error message, note its exact wording.
3. Try once more (a transient network error can cause a single failure).
4. If it still fails, email **support@opsiq.solutions** with the details below. Account creation does not
   require any payment or email-verification step, so a persistent failure is something we want to see.

## What to do if diagnosis fails
1. Confirm you filled the **required fields** (business name, business type, the main issue, and a
   short problem statement).
2. Note the exact error text and roughly when it happened.
3. Re-run the diagnosis once — diagnosis is deterministic, so a clean retry usually either succeeds or
   reproduces the same message (useful for us).
4. If it keeps failing, email **support@opsiq.solutions** with the details below. No payment or AI key is
   ever required to run a diagnosis, so this should always work for valid inputs.

## What to do if the dashboard does not load
1. Refresh the page once.
2. Make sure you're **signed in** (if your session expired, sign in again at `/login`).
3. If you just signed up and the dashboard looks empty, that's expected until you **run your first
   diagnosis** — start one and your findings, recommendations, and actions will appear.
4. If the page still won't load, email **support@opsiq.solutions** with the details below.

## Account access / lockout (beta note)
During beta, **automated password reset and email verification are not yet available**. If you're
locked out or can't access your account, email **support@opsiq.solutions** from the address you signed up
with and we'll help you recover access manually.

## What to include in a support request
Please paste the following so we can resolve it on the first reply:
- **Your account email** and **workspace name**.
- **What you were trying to do** (e.g., "running a diagnosis", "loading the dashboard").
- **The exact error message** you saw (copy/paste or screenshot).
- **The page URL** where it happened.
- **Approximate time** (with timezone) it occurred.
- **Browser and device** (e.g., "Chrome on Windows", "Safari on iPhone").
- Anything you already tried (refresh, retry, sign in again).

Please do **not** send passwords or any sensitive financial details — we never need them.

## Billing / payment support
**Not applicable during beta.** Rebilix has no payment provider configured: no credit card, no
subscription, no charges. If you ever see a message implying payment is required to sign up, log in, or
run a diagnosis, that's a bug — please report it to **support@opsiq.solutions**.
