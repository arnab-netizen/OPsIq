# Module 14 UI slice

## Objective
Implement UI for Module 14 — Final UX, Client Portal, Admin Portfolio.

## Rules
- No business logic in UI.
- Consume backend APIs or server actions only.
- Show loading, empty, failure, and not-found states for every screen or panel created in this slice.
- Surface current governed state honestly.
- Do not invent fields not provided by backend.

## Core rule
Beginner vs expert behavior must be meaningfully different.

## Acceptance criteria
- UI reflects real backend data.
- Failure and empty states exist.
- No page depends on missing schema fields.

## Required screens or panels
- beginner-mode experience
- expert-mode experience
- client portal
- admin portfolio dashboard

## Required display elements
- business condition
- intervention mode
- intervention phase
- risk flags
- health status
- key blockers
- major shocks
- current priorities
