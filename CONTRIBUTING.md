# Contributing to OpsIQ

Thanks for your interest in OpsIQ. This repository is public so the code is inspectable and auditable, but it is **not currently accepting external code contributions** (pull requests from outside the core team will generally not be merged).

## What you can do

- **Report bugs or unexpected behavior**: open a [GitHub issue](../../issues) with clear reproduction steps.
- **Ask questions**: open an issue, or see [SECURITY.md](SECURITY.md) if the question is security-sensitive.
- **Report a security vulnerability**: please follow [SECURITY.md](SECURITY.md) rather than a public issue.

## Why contributions are closed for now

OpsIQ is in a controlled beta with an active internal development process, governed by strict internal review and merge policies. This may change in the future; if it does, this file will be updated with contribution guidelines (coding standards, PR process, and how to run the test suite locally).

## Local development

If you want to run the project locally to explore the code or verify a bug report, see the [README](README.md#local-development) for setup instructions.
