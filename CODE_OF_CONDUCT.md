# Code of Conduct

This repository is public and issues are open for bug reports and questions. To keep that space usable for everyone:

- Be respectful. Disagreement is fine; personal attacks, harassment, and discriminatory language are not.
- Stay on topic. Keep issues focused on OpsIQ itself (bugs, questions, security reports per [SECURITY.md](SECURITY.md)).
- No spam, self-promotion, or off-topic solicitation.

Maintainers may close, lock, or delete issues/comments that violate this, and may block repeat offenders. There is no separate enforcement contact beyond opening an issue or, for sensitive matters, emailing support@opsiq.solutions.
